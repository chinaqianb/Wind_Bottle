# Wind_Bottle
当你想在生存游玩风弹的，时候却发现杀死旋风人 只能合成8个风弹 ，
这模组会很好的帮你解决这个问题，它可以通过三种方式：

手持玻璃瓶右键流浪者

手持玻璃瓶右键旋风人

主手为玻璃瓶或在以玩家为半径10格范围内有玻璃瓶掉落物且玩家或玻璃瓶掉落物速度大于等于（>=）1（1block/tick）持续5s

以获得风瓶,然后通过许多种[分解方式](#craft)可以将它分解为风弹，并返还一个玻璃瓶。

When you want to play wind charge in survival, you find that killing the breeze can only be combined into 8 wind charge.
This mod will help you solve this problem in three ways:

Right-click the stray with a glass bottle

Right-click the breeze  holding a glass bottle

The main hand is a glass bottle, or there are glass bottle drops within a radius of 10 blocks from the player, and the player or the glass bottle drop speed is greater than or equal to (>=)1 (1block/tick) for 5s

to obtain an Wind Bottle, which can then be broken down into a Wind charge in [a number of ways](#crafting) to dismantle and return a glass bottle.
